# Cinema Radio stations

The right-hand wheel selects five continuous stations. Drag upward/downward, scroll over the dial, tap for the next station, or use arrow keys; Home/End select the first/last station. Each joins its own current UTC position, not the start of a film. The station name replaces Up next on the screen.

Changing while powered on plays a soft 240 ms filtered-static tuning sound at a level proportional to volume and remaining sleep fade, followed by the existing audio fade-in. Tuning while off is silent. The selected station is remembered locally when browser storage is available.
